# GLHAC 홈페이지 (glhac.com)

지엘할랄인증센터 소개 페이지와 **익명 비공개 문의 게시판**입니다.
할랄 인증 시스템(`glhac.co.kr`)과는 별개 도메인이고, 서로 로그인 상태를 넘겨받습니다.

## 구성

```
index.html          한 화면씩 좌우로 넘기는 6장 슬라이드 + 인트로
board/index.html    문의 게시판 — 무가입 등록 · 비밀번호로 재열람 · 담당자 응대
assets/             빌드된 SPA 번들(원본 프로젝트에서 산출)
intro/              인트로 영상·배경
about-visual-*.jpg  2번 화면 시안 — 언어별(ko·en·id)
tools/make_poster.py  시안의 한국어만 갈아 끼워 en·id 판을 만든다
```

## 화면 구성

1. 히어로 + 바로가기 · 2. 센터소개 · 3. 인증절차 · 4. 서비스 · 5. 할랄정보 · 6. 상담신청·연락처

넘기는 방법: 마우스 휠(세로로 굴려도 넘어감) · 좌우 화살표 · 키보드 `←` `→` `Home` `End` · 아래 점

폭 1024px 미만에서는 슬라이드를 끄고 세로 스크롤로 둡니다 — 좁은 화면에서는
가로로 넘기며 안에서 또 세로로 굴려야 해서 축이 둘이 됩니다.

## 게시판

가입을 요구하면 문의가 줄고, 공개로 두면 어느 업체가 무슨 원료로 고민 중인지
경쟁사에 보입니다. 그래서 **무가입 + 내용은 비공개**입니다.

- 목록에는 제목·가린 연락처·상태까지만 (`010-****-5678`)
- 내용은 글 비밀번호를 아는 사람과 로그인한 담당자만
- 글번호는 `20260912-00001` 꼴 — 32자리 내부 키를 사람이 부를 수 없습니다
- 비밀번호에 연락처 숫자를 4자리 이상 쓸 수 없습니다(목록에 연락처가 일부 보이므로)

API 는 `glhac.co.kr` 백엔드를 씁니다(도메인이 달라 CORS 허용이 필요합니다).

## 배포

```bash
bash scripts/deploy.sh              # 백업 → 전송 → 확인
bash scripts/deploy.sh --dry-run    # 무엇이 바뀌는지만
bash scripts/deploy.sh --rollback   # 직전 백업으로
```

가비아 서버 `/var/www/glhac-home` 으로 나갑니다. nginx 가 `/board/` 에
`no-cache` 를 걸어 두어 고친 화면이 바로 반영됩니다.
